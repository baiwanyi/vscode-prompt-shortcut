# 2026-10-31 工作记录

## 修改内容摘要

新建 VSCode 扩展 `webian-prompt`（微边提示词），用于 AI 提示词管理：

1. 技术栈落地：TypeScript 7.0.2 + React 19.3.1 + Vite 8 + Tailwind CSS 4（CSS-first `@theme`）+ shadcn/ui 风格组件 + Lucide。
2. 逆向确认 CodeBuddy 4.12 的内部命令通道：`tencentcloud.codingcopilot.sendToChat`（handler 接收 `{ prompt, mode }`，内部 `autoSend: true` + 新建对话），由 `CommandRegistry` 统一注册；命令 ID 前缀来自 `COMMAND_ID_PREFIX = 'tencentcloud.codingcopilot.'`。
3. 扩展宿主：`CodeBuddyBridge` 实现「focus 聊天视图激活扩展 → 校验命令存在 → 发送」链路，含剪贴板降级；`PromptStore` 基于 globalState 持久化并做归一化；`PromptSidebarProvider` 承载 Webview、CSP nonce 与消息路由。
4. 侧边栏 UI：提示词卡片（发送 / 复制 / 编辑 / 上移下移 / 删除）、搜索、新增与编辑对话框、CodeBuddy 连接状态提示、Toast。
5. 右键菜单「微边代码」：`/fix <相对路径>` 与 `/cr <相对路径>`，有选区时追加行号范围。
6. 内置四条预设提示词：提交到 Git、推送到 Git、按顺序实施、按推荐实现。

## 关键技术结论

- `tsconfig.json` 在 TS 7 下必须移除 `baseUrl`，`paths` 需写 `./` 前缀的相对路径。
- `typescript-eslint@8.72` 在检测到 TS ≥ 7 时直接抛错（upstream #10940 未支持），故本项目不接入 ESLint，质量门禁改为 `pnpm run typecheck`。
- pnpm 12 的构建脚本白名单字段为 `allowBuilds`，写在 `pnpm-workspace.yaml`；旧字段 `onlyBuiltDependencies` 不再生效。
- Vite 配置需使用 `.mts` 扩展名，否则 `configLoader: 'native'` 会告警 ESM/CJS 混用。

## css-lcurlyexpected 真正成因（重要）

- 上述 19 条 `css-lcurlyexpected` 的真实触发点是**文件头部注释里出现了完整的 at-rule 关键字 `@theme` 文本**。
  Tailwind 语言服务不跳过注释内容，把注释里的 `@theme` 当作真实指令解析，导致 `:root` 块起整篇状态错乱，
  报错位置落在块内各条自定义属性上（列号指向 `var` 首字母），换文件 URI 后依然复现。
- 定位方式：最小可复现文件逐段加回。`@theme` / `@theme inline` / `oklch()` / 嵌套 `var()` / 属性选择器 /
  `::-webkit-scrollbar` / 中文注释本身均无问题，唯独注释含 at-rule 关键字时必现。
- 规避约定：本项目 CSS 注释中不得写出完整 at-rule 关键字（用「主题块」「导入语句」等中文描述代替），
  已在文件头部注释中注明。
