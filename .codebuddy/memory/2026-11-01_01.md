# 2026-11-01_01

## 右键子菜单插到「快速查看」与「查找所有引用」之间

- 查证（VS Code 1.144 内核与内置扩展）：「快速查看」由内核注册为 `EditorContextPeek` 子菜单，`group: navigation, order: 100`；
  「查找所有引用」由内置 `references-view` 贡献，`group: 0_navigation@1`（实现/调用层次/类型层次依次 @2/@3/@4）。
- 处理：`editor/context` 的 group 由 `o_quickcommand@1` 改为 `0_navigation@0`——与「快速查看」不同组（navigation 组整体在前），
  order 0 小于 @1，正好落在两者之间并自带分割线。
- 附带确认：本机 VS Code 为 1.144.0，与 `engines.vscode` 一致。
- 验证：`prettier --check package.json` 通过、`vsce ls` 通过；实际位置需在扩展开发宿主中人工确认。

## 快捷命令与「查找所有引用」之间补分割线

- 现象：`0_navigation@0` 与「查找所有引用」（`0_navigation@1`）同组，菜单同组内不画分割线，只有上侧跨组那一条。
- 处理：改为独立组 `0_a_quickcommand@1`——组名前缀 `0_a` 的字母序介于（被前置的）`navigation` 与 `0_navigation` 之间，
  整体位置不变，且上下两侧都跨组，各得一条分割线。
- 验证：`prettier --check package.json` 通过、`vsce ls` 通过；实际渲染需人工确认。
