## 修复发布流程找不到 vsix 产物

- 现象：`pnpm run release` 报「没有生成 releases\vscode-prompt-shortcut-0.1.0.vsix」，退出码 1。
- 根因：`vsce package --out releases/` 在 `releases` 目录不存在时把 `releases/` 当作文件名，在仓库根写出了一个名为 `releases` 的 vsix 文件；该文件既不在 `releases/` 下，也不被 `.gitignore` 的 `releases/` 规则忽略（目录规则不匹配同名文件）。
- 修复：新增 `scripts/package.mjs`，先 `mkdirSync` 建目录，再用完整文件路径 `--out releases/<name>-<version>.vsix` 调 vsce；`package.json` 的 package 脚本改为 `pnpm run compile && node scripts/package.mjs`。
- 涉及文件：`scripts/package.mjs`（新增）、`package.json`。
- 验证：删除 `releases` 目录后 `pnpm run package` 正常产出 `releases/vscode-prompt-shortcut-0.1.0.vsix`（11 files, 177 KB）；改动文件 prettier 与 eslint 均通过。
