## destructive 配色对齐 shadcn 默认
- 现象：修好样式覆盖后，「删除」的红仍与 shadcn 默认不一致，偏暗发灰。
- 根因：--destructive 取自 VSCode 的 inputValidation.errorBorder（输入框边框语义），深色主题下偏暗，作前景与 10% 叠底都会失真。

  --destructive-foreground 仍用 errorForeground（容量告警等文字场景）。
  同时在 dropdown-menu 的 Content/SubContent 补 dark 变体的 destructive 高亮 20%（important），与 shadcn 的 dark:bg-destructive/20 对齐。
- 涉及文件：src/webview/styles.css、src/webview/components/ui/dropdown-menu.tsx。
- 验证：构建后 CSS 中 --destructive 为 oklch(57.7% .245 27.325) / oklch(70.4% .191 22.216)，dark 的 20% 规则输出在 10% 之后；前景色规则均为 color:var(--destructive) 且无 accent-foreground 覆写；typecheck / eslint / prettier 通过；pnpm run package 安装成功。视觉需人工确认。
