## 对齐 zhai.vscode 的 Webview HTML 写法（取代前面的占位符 / base 方案）

  - `PromptSidebarProvider` 删除 `readHtmlTemplate` / `htmlTemplate` / `buildHtml` / `CSP_PLACEHOLDER` / `readFileSync`，
