# 预设提示词

首次激活时写入扩展全局存储，此后与用户自建模板完全等价：可编辑、可排序、可删除，删空也不会被自动补回。

格式约定：

- `## 名称` 起一条，名称即卡片标题；
- 紧随其后的 `- icon: xxx` 与 `- mode: xxx` 是元数据，取值见 `src/shared/types.ts`；
- 正文放在标记为 `text` 的代码块内，留空表示发送时回退为名称。

## 排查遗留代码

- icon: shieldCheck
- mode: ask

```text
请对项目代码库进行全面评估，系统性地识别并归类孤儿代码、死代码及旧代码残留。评估需覆盖以下方面：孤儿代码（无调用方或被引用的函数、类、模块）、死代码（逻辑上不可达或条件恒不成立的代码路径）、旧代码残留（被新实现替代但未清理的历史代码、过时注释、废弃的配置项与依赖）。对每类问题给出所在位置、判定依据、影响范围（如增加维护成本、混淆逻辑、潜在安全隐患）及清理优先级建议。最终输出结构化评估报告，按类别汇总问题清单，并给出整体清理建议与风险提示。
```
